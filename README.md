# Hey there! 👋 I'm José Felipe

**Full-stack developer, back-end at heart.** I like building complete systems: APIs, web and mobile apps, AI integrations and the infrastructure they run on.

📍 Faro, Portugal · 🎓 BSc in Internet Systems (IFC, Brazil) · 📚 MSc in Informatics Engineering, Universidade do Algarve *(ongoing)* · 🔐 Next: Cybersecurity postgrad

---

### 💡 What I know

**⚙️ Back-end**
- REST APIs and WebSockets with **Node.js / TypeScript** (NestJS, Fastify, Express), **Python**, **PHP / Laravel**, **Java** and **C# / .NET**
- Multi-tenant SaaS architecture, modular monoliths and services
- Event-driven systems with message queues (**RabbitMQ**, **Kafka**) and background workers
- Authentication and authorization: **OAuth2**, JWT, httpOnly cookies + CSRF, roles and rate limiting

**🗄️ Data**
- **PostgreSQL** data modelling, migrations, constraints and query tuning
- **Redis** for caching, queues, rate limits and real-time state
- ORMs: **Prisma**, Drizzle, Eloquent
- Backups and recovery, data audits and integrity checks

**🎨 Front-end**
- **React** (hooks, lazy-loaded routes), **Next.js**, **Vite**, **Tailwind CSS**
- Design systems and reusable components, i18n, accessibility, dark mode

**📱 Mobile**
- Native Android with **Kotlin + Jetpack Compose**
- Cross-platform with **Flutter / Dart** and **React Native**
- **Bluetooth Low Energy**, GPS and background services on Android

**🤖 AI**
- LLM integration in products: chatbots, agents with tool calling, prompt design
- **RAG** with embeddings and vector search, long-term memory for agents
- Local models with **Ollama**, speech-to-text with **Whisper**

**☁️ DevOps & infrastructure**
- **Docker / Docker Compose**, Linux servers (VPS), SSH, VPN (WireGuard, Tailscale)
- **Cloudflare** Workers, Pages and DNS
- CI/CD with **GitHub Actions**, off-site backups to object storage

**🔌 Integrations**
- Payments with **Stripe**: checkout, subscriptions, webhooks, proration, 3-D Secure
- **Meta / WhatsApp Business** APIs, marketplace APIs (eBay), web scraping
- Multi-currency and exchange rates, time zones and dates done right

**🧪 Quality**
- Unit and integration tests (Jest, Vitest, Pytest), end-to-end tests with **Playwright**
- Code review, error monitoring and production debugging
